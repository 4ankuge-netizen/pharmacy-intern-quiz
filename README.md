# 薬学実習クイズ

薬学実習生向けのクイズアプリです。代表的8疾患の薬物治療を、一問一答形式で学べます。

スマートフォンのブラウザで開いて使います。ホーム画面に追加すると、
アプリのように起動できます。ログインは不要で、学習記録は端末の中だけに保存されます。

## できること

- **8疾患のカテゴリー別出題** — がん / 高血圧症 / 糖尿病 / 心疾患 / 脳血管障害 /
  精神神経疾患 / 免疫・アレルギー疾患 / 感染症
  (このほか計算問題・社会常識・倫理観の枠を用意していますが、問題は未作成です)
- **1回10問** — 問題プールからランダムに出題。出題順も選択肢の並びも毎回変わります
- **弱点復習モード** — 間違えた問題だけをもう一度
- **正答率** — カテゴリー別の正答率を表示
- **ブックマーク** — 気になった問題に印を付けて後で見返す
- **連続学習日数** — 続けた日数を表示
- **オフライン対応** — 一度開けば、電波がなくても使えます

## ⚠️ 内容についての大切なお断り

**このアプリは学習の補助を目的としたものです。実際の実習・業務では、
必ず最新の添付文書・インタビューフォーム・ガイドラインの原本で確認してください。**

問題データには「PMDAの一次資料で内容を確認済みかどうか」の印が付いており、
**アプリは確認済みの問題だけを出題します**。確認が済んでいない問題は
データとしては保持していますが、画面には表示されません。

現在の確認状況は [docs/verification-notes.md](docs/verification-notes.md) を参照してください。
確認作業の中で内容に誤りが見つかった問題は、削除して理由を記録しています。

## 出典の方針

問題は次の資料からのみ作成します。

| 種類 | 可否 |
|---|---|
| PMDAの添付文書・インタビューフォーム | ○ |
| 学会・公的機関が公開する診療ガイドライン | ○ |
| 個人のブログ・まとめサイト | × |

確認済みの問題には、実際に確認した資料のURLと確認日が記録されており、
アプリの解説欄からその資料を開けます。

## 開発者向け

外部のライブラリを使わない、素のHTML/CSS/JavaScriptで作られています。
ビルド作業は不要です。

```bash
npm start   # 開発用サーバーを起動し、http://localhost:8080 で確認
npm test    # 自動テストを実行
```

### ファイルの構成

| 場所 | 役割 |
|---|---|
| `index.html` / `css/` | 画面の見た目 |
| `js/app.js` | 画面と各部品のつなぎ込み |
| `js/quiz-engine.js` | 出題の選択・採点・並び替え |
| `js/storage.js` | 学習記録の保存(端末内) |
| `js/stats.js` | 正答率の計算 |
| `js/validate-questions.js` | 問題データの形式チェック |
| `data/questions.json` | 問題データ |
| `tools/` | PMDA確認作業のための道具 |
| `docs/` | 設計書と確認作業のメモ |

### 問題データの形式

```json
{
  "id": "cancer-beginner-001",
  "category": "cancer",
  "difficulty": "beginner",
  "type": "single",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "correctIndex": 0,
  "explanation": "解説",
  "source": { "name": "資料名", "url": "https://...", "confirmedDate": "2026-08-26" },
  "verified": true
}
```

`verified` が `true` の問題だけがアプリに出題されます。
