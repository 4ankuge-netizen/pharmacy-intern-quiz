# 薬学実習クイズ

薬学実習生向けのクイズアプリです。薬物治療を一問一答形式で学べます。

スマートフォンのブラウザで開いて使います。ホーム画面に追加すると、
アプリのように起動できます。ログインは不要で、学習記録は端末の中だけに保存されます。

## できること

- **カテゴリーと難易度を選んで出題** — 初級 / 中級 / 上級の3段階
- **1回10問** — 問題プールからランダムに出題。出題順も選択肢の並びも毎回変わります
- **ふりかえり** — 解き終わったあと、その回の問題を1問ずつ開いて解説と出典を読み返せます
- **弱点復習モード** — 間違えた問題だけをもう一度
- **正答率** — カテゴリー別の正答率を表示
- **ブックマーク** — 気になった問題に印を付けて後で見返す
- **連続学習日数** — 続けた日数を表示
- **利用者の切り替え** — 1台の端末を複数の実習生が使えます。成績・ブックマーク・
  連続日数は利用者ごとに分かれて保存され、混ざりません
- **成績の書き出し** — カテゴリー別・難易度別の成績を文字にまとめてコピーできます
- **オフライン対応** — 一度開けば、電波がなくても使えます
- **ダークモード** — 端末の設定に合わせて自動で切り替わります

## ⚠️ 内容についての大切なお断り

**このアプリは学習の補助を目的としたものです。実際の実習・業務では、
必ず最新の添付文書・インタビューフォーム・ガイドラインの原本で確認してください。**

問題データには「一次資料で内容を確認済みかどうか」の印(`verified`)が付いており、
**アプリは確認済みの問題だけを出題します**。

確認作業の中で内容の誤りが見つかった問題は、修正または削除して理由を記録しています
([docs/question-revisions.md](docs/question-revisions.md))。
たとえば「急性冠症候群ガイドラインの2023年改訂版は存在しない(正しくは2018年改訂版)」
「抗リン脂質抗体症候群の脳梗塞再発予防でDOACは推奨度E」といった訂正が含まれます。

医療の基準は改訂されます。**解説に書かれた確認日より後に内容が変わっている可能性**が
あることを前提にお使いください。

## 出典について

問題は次の資料からのみ作成しています。

| 種類 | 可否 |
|---|---|
| PMDAの添付文書・インタビューフォーム | ○ |
| 学会・公的機関が公開する診療ガイドライン | ○ |
| e-Gov法令検索の法令・省令 | ○ |
| 厚生労働省が公開する通知・指針・国家試験問題 | ○ |
| 個人のブログ・まとめサイト | × |

各問題には、実際に確認した資料の名称・URL・確認日が記録されており、
アプリの解説欄からその資料を開けます。

### 厚生労働省の公開資料について

「国家試験」カテゴリーの問題文・選択肢・正答は、厚生労働省が公開している
[薬剤師国家試験の問題及び正答](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iyakuhin/yakuzaishi-kokkashiken/index.html)
を出典としています。同省サイトのコンテンツは
[利用規約](https://www.mhlw.go.jp/chosakuken/index.html)(公共データ利用規約 第1.0版)に基づき、
出典を明示して利用しています。

- **解説は厚生労働省の公開資料には含まれていません。** 同省は問題と正答のみを公開しており、
  本アプリの解説は独自に作成したものです。内容の責任は本アプリ側にあります。
- PDFからテキストを取り出す際に失われた空欄記号の補い、および図表を参照する
  選択肢の除外など、**編集・加工を行った箇所**があります。加工の内容は各問題の
  記録([docs/question-revisions.md](docs/question-revisions.md))に残しています。
- 構造式・グラフ・人体図などが選択肢そのものになっている問題は、
  テキストでは成立しないため収録していません。

### 診療ガイドラインについて

学会の診療ガイドラインには無断複製・転載を禁じているものがあります。
本アプリでは**原文を転載せず、内容を要約して独自の文章で解説を作成**しています。
出典としてガイドライン名とURLを明示しています。

## 開発者向け

外部のライブラリを使わない、素のHTML/CSS/JavaScriptで作られています。
ビルド作業は不要です。

```bash
npm start   # 開発用サーバーを起動し、http://localhost:8080 で確認
npm test    # 自動テストを実行(48件)
```

### ファイルの構成

| 場所 | 役割 |
|---|---|
| `index.html` / `css/` | 画面の見た目 |
| `js/app.js` | 画面と各部品のつなぎ込み |
| `js/quiz-engine.js` | 出題の選択・採点・並び替え |
| `js/storage.js` | 学習記録の保存(端末内・利用者ごと) |
| `js/stats.js` | 正答率の計算 |
| `js/validate-questions.js` | 問題データの形式チェック |
| `data/questions.json` | 問題データ |
| `data/categories.json` | カテゴリーの一覧 |
| `tools/` | 資料の取得と、問題の追加・確認のための道具 |
| `docs/` | 設計書と、問題ごとの修正記録 |

資料を取ってくる道具は、取得先ごとに分かれています。

| 道具 | 取得先 |
|---|---|
| `tools/fetch-pmda-documents.mjs` | PMDAの添付文書 |
| `tools/fetch-interview-form.mjs` | PMDAのインタビューフォーム |
| `tools/fetch-guideline.mjs` | ガイドライン等のPDF |
| `tools/fetch-web-source.mjs` | 公的機関・学会の解説ページ(公開元の許可リストあり) |
| `tools/fetch-law.mjs` | e-Gov法令検索の法令・省令 |
| `tools/extract-exam-pdf.py` | 国家試験PDFの文字起こし(`pip install pymupdf` が必要) |

取得した資料は `.pmda-cache/` などに保存されますが、
容量が大きく再取得できるため、いずれもGitの管理対象外です。

### 問題データの形式

```json
{
  "id": "cancer-beginner-001",
  "category": "cancer",
  "difficulty": "beginner",
  "type": "single",
  "question": "問題文",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "correctIndex": 0,
  "explanation": "解説",
  "source": { "name": "資料名", "url": "https://...", "confirmedDate": "2026-08-26" },
  "verified": true
}
```

- `verified` が `true` の問題だけがアプリに出題されます。
- 選択肢は4つが基本ですが、国家試験の問題は5つです。
  正解の位置は選択肢の数ごとに均等に散らしてあり(`tools/shuffle-choices.mjs`)、
  さらに表示のたびに並び替わります。
