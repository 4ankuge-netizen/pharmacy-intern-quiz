ホーム画面に置いて、アプリのように使う

iPhone / iPad

  1. Safari で上のQRコードを開く
  2. 画面下の共有ボタン（□に↑）を押す
  3. メニューを下にたどって
    「ホーム画面に追加」を押す
  4. 右上の「追加」を押す

Android

  1. Chrome で上のQRコードを開く
  2. 右上の「︙」を押す
  3. 「アプリをインストール」
    （または「ホーム画面に追加」）を押す
  4. 「インストール」を押す
使うときのポイント
  • iPhoneでホーム画面に追加するときは、かならず Safari で開いてください。Chromeなど他のアプリからでは追加できません。
  • 成績はその端末の中だけに保存されます。同じ端末を2人で使う場合は、画面右上の利用者名から利用者を追加して切り替えてください。
  • 一度開いたあとは、電波がなくても使えます。
  • 問題が増えたり直ったりしたときは、次に開いたときに自動で新しくなります。
