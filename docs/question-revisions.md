- 問題: 狭心症・心筋梗塞で冠動脈の状態を調べ、必要に応じて治療も行える検査・手技はどれか。
- 選択肢: 冠動脈カテーテル検査(心臓カテーテル) / 腹部超音波検査 / 骨密度検査 / 肺機能検査
- 正解: 冠動脈カテーテル検査(心臓カテーテル)
- 解説: 冠動脈の狭窄が強い場合や完全に詰まっている場合は、冠動脈カテーテル治療(PCI)や冠動脈バイパス手術が選択されます。最近ではFFR(冠血流予備比)検査で治療の必要性を評価してから治療することがガイドラインで推奨されています。
